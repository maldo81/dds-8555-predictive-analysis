# DDS-8555 Predictive Analysis

Public submission repository for DDS-8555 Predictive Analysis coursework.

## Contents

- `Week 1` through `Week 8`: assignment deliverables, including notebooks, reports, and exported files.
- `data/submissions`: lightweight Kaggle submission files and submission-status evidence used by the notebooks.
- `deliverables-index.md`: index of submitted course artifacts.
- `requirements-datascience.txt`: Python package reference for reproducing the notebooks locally.

## Data Note

Raw Kaggle datasets are intentionally excluded from this public repository.  The notebooks reference Kaggle datasets that should be downloaded from the original competition pages when rerunning the work locally.  Large generated SF Crime submission files and internal QA render artifacts are also excluded to keep the public repository focused on assignment deliverables.
